# CLA signatures

This branch holds only the signatures to the andeye Contributor Licence Agreement
([CLA.md](https://github.com/andeyePro/helpandeye/blob/main/CLA.md)), written by the CLA
workflow (`.github/workflows/cla.yml` on `main`) to `signatures/version1/cla.json` when someone
signs on a pull request. It is kept apart from `main` so that signing never changes the branch
the website is deployed from, and `main` can stay protected. Do not merge it into another branch.
